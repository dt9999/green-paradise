# グリーンパラダイス iPhone版

Web版のゲーム一式をアプリ内に入れて動かすiOSプロジェクトです。通信なしでもゲーム本体を起動できます。

- アプリ名: グリーンパラダイス
- Bundle ID: `jp.dt9999.greenparadise`
- アプリ版: `1.0.0`
- ゲーム版: `0.6.0`
- 画面: iPhone横向き
- 保存: 端末内のみ
- 広告・解析・会員登録: なし

ゲームを変更したあとは、このフォルダで `npm run sync` を実行します。Xcodeを開くときは `npm run open` を実行します。

App Storeへ出すには、保護者のApple AccountでApple Developer Programへの登録、Xcodeの署名設定、App Store Connectのアプリ登録、説明文とスクリーンショットの登録が必要です。

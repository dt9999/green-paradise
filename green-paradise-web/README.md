# グリーンパラダイス 0.2.0

小さなロボットが、足あとをみどりに変える横スクロールゲーム。
外部ライブラリ不要の HTML / CSS / Canvas ゲームです。

## 遊ぶ

このフォルダで `npm start` を実行するとブラウザで開きます。
`index.html` を直接開くこともできます。GitHub Pages では、このフォルダを公開します。

- A / D または左右矢印: 左右に移動
- W / 上矢印 / Space: ジャンプ
- S / 下矢印: 空中から急降下
- E: 葉っぱを発射。葉っぱアイテムを拾ったステージのみ、1発1pt
- スマホ: 左側の移動ボタン、右側のジャンプ・急降下ボタン
- メニュー: 一時停止、地図、音、全画面、各種ボーナス

普通のジャンプで敵に当たるとダメージ。急降下で上から攻撃してください。
草を生やす・宝石を拾う・敵を倒すとポイントが増え、大きな木でクリア。
クリアするとボーナスが入り、次のステージが無料で開きます。
ポイントで先のステージを開くこともできます。

## 50ステージ / 10の世界

| ステージ | 世界 | 最後に待つボスの技 |
| --- | --- | --- |
| 1–5 | はじまりの森 | 地面を走る衝撃波 |
| 6–10 | こはくの砂漠 | 突進 |
| 11–15 | 水晶のどうくつ | 一定時間で消えるバリア |
| 16–20 | さびいろ工場 | 予告の印に降る火の玉 |
| 21–25 | きのこの湿地 | 毒の水たまり |
| 26–30 | しずかな雪山 | 大ジャンプと着地の衝撃波 |
| 31–35 | 夕やけの峡谷 | 予告の印に落ちる雷 |
| 36–40 | 星あかりの森 | 扇状の弾 |
| 41–45 | 雲の上の遺跡 | 突進と速い衝撃波 |
| 46–50 | さいごの大樹 | 複数の技を切り替える最終ボス |

ステージ50のボスを倒し、大樹に触れるとエンディング。
森が育ち、葉が舞う演出が始まります。

## バランスと保存

- 初期エネルギー4、急降下ダメージ2、葉っぱダメージ1。
- 葉っぱドロップ10%。アイテム運1レベルごとに+3%、最大22%。
- こうげき強化は急降下+1、葉っぱ+0.5。葉っぱは常に急降下の半分。
- 草1本1pt、宝石10pt、通常敵25〜60pt、ボス150〜420pt。
- クリア100+ステージ番号×12pt。ボス面はさらに180pt。
- 日付ごと50pt、応援は10秒ごと5pt。広告は本物ではなく、おためし30pt（30秒間隔）。
- 旧バージョンと同じ `greenParadiseSaveV1` に保存。ポイント・強化・進行を引き継ぎます。
- 旧5ステージクリア済みの保存データでは、ステージ6が自動で開きます。
- 買って飛ばしたステージをクリア済み扱いにしないよう、クリア済み番号を別に記録します。
- 記録は同じブラウザ・同じURLに保存されます。端末間の共有やオフライン対応はありません。

## 開発・確認

`world.js`: ステージ生成、物理、敵、戦闘、保存データ検証。
`art.js`: 地域ごとの風景、キャラクター、ボス、演出の描画。
`game.js`: 画面、入力、音、ポイント、ブラウザ保存。

`npm test` で50面の足場、左右両方向のジャンプ、ボス技、ダメージ、ドロップ、保存移行を確認します。
ブラウザテストは Node.js 20以上と Playwright の Chromium / WebKit が必要です。
ローカルサーバー起動後、`TEST_URL=http://127.0.0.1:4173 node tests/browser.cjs`。
Playwright が別の場所にある場合は `PLAYWRIGHT_MODULE` でモジュールの絶対パスを指定できます。
テストは独立したブラウザ保存領域を使い、実際のプレイヤーの記録は変更しません。

更新時は `world.js` の `VERSION` と `index.html` のバージョン・CSS/JSのクエリをそろえて増やします。
スタートボタンの下の中央で、新しいバージョンになったか確認できます。
iPhone実機での長押しメニューやホーム画面からの表示は、公開後にも実機確認してください。

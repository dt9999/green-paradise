# グリーンパラダイス 0.4.0

小さなロボットが、足あとをみどりに変える横スクロールゲーム。
外部ライブラリ不要の HTML / CSS / Canvas ゲームです。

## 遊ぶ

このフォルダで `npm start` を実行するとブラウザで開きます。
`index.html` を直接開くこともできます。GitHub Pages では、このフォルダを公開します。

- A / D または左右矢印: 左右に移動
- W / 上矢印 / Space: ジャンプ
- S / 下矢印: 空中から急降下
- E: 葉っぱを発射。葉っぱアイテムを拾ったステージのみ、1発1pt
- スマホ: 左側の移動ボタン、右側のジャンプ・急降下ボタン
- メニュー: 一時停止、地図、音、全画面、各種ボーナス

普通のジャンプで敵に当たるとダメージ。急降下で上から攻撃してください。
草を生やす・宝石を拾う・敵を倒すとポイントが増え、大きな木でクリア。
クリアするとボーナスが入り、次のステージが無料で開きます。
ポイントで先のステージを開くこともできます。

## エリアごとの仕掛け

既存作品の画像・音楽・コースは使わず、横スクロールゲームの定番の遊びを独自の草木の世界に取り入れています。
全16種類。初登場時には短いヒントが出ます。メニューの「仕掛けのヒント」からいつでも読み直せます。

| エリア | 主な仕掛け |
| --- | --- |
| 森 | 葉っぱバネ、左右に動く丸太 |
| 砂漠 | 歩くと遅くなる砂、矢印方向への追い風 |
| 水晶 | 上下リフト、点滅して消えるほたる足場 |
| 工場 | 左右のベルト、予告して吹き出す蒸気 |
| 湿地 | 急降下でより高く跳ねるキノコ、崩れる足場 |
| 雪山 | 慣性で滑る氷、予告して落ちるつらら |
| 峡谷 | ジャンプで浮き上がる上昇気流、高い移動足場 |
| 星の森 | 急降下スイッチ、そこから育つ葉っぱの橋、ほたる足場 |
| 遺跡 | 急降下で壊せる岩、リフト、スイッチ、崩れる足場 |
| 大樹 | これまでの仕掛けを組み合わせた道 |

最初は広い地面、後半では組み合わせて登場。ステージ1は基本操作の説明のあとにバネが登場します。
上のルートには宝石を追加。落ちてもやり直せる地面を残し、ボスのいる最後の足場は仕掛けを置いていません。
穴そのものは残るので、空中でも左右に動いて着地場所を調整してください。
ほたる足場は5秒周期で3.6秒間出現、消える0.8秒前から点滅。
崩れる足場は乗って0.7秒後に消え、3秒後に復活。スイッチと壊した岩はその挑戦中のみ状態を保ちます。
バネは自動で跳ね、キノコは急降下でさらに高く跳ねます。上昇気流の中でも急降下できます。
追加の操作ボタンやポイント消費はありません。既存のセーブは維持します。

## バランスと保存

- 初期エネルギー4、急降下ダメージ2、葉っぱダメージ1。
- 強化上限は全種類7。購入済みレベルとポイントはそのまま引き継ぎ、能力上昇幅だけ再調整しています。
- 葉っぱドロップ10%。アイテム運1レベルごとに+1.5%、最大20.5%。
- こうげき強化は急降下+0.5、葉っぱ+0.25。基本威力は急降下の半分。
- 葉っぱは最大3発分のゲージ、2秒で1発回復、発射間隔0.65秒、射程約368。失敗した発射ではポイントを消費しません。
- ボスの装甲に対する葉っぱは基本威力の25%。急降下が命中すると2.4秒間、葉っぱが基本威力で通ります。
- ボスのバリアは装甲とは別で、バリア中は両方の攻撃を防ぎます。急降下が防がれた場合、弱点は開きません。
- ジャンプ速度は550+16×レベル、移動速度は205+10×レベル。基本地形の穴はレベル0・4・7の組み合わせで左右に越えられることをテスト。仕掛けの影響や乗降は別のテストで確認しています。
- エネルギーは奇数レベルでハート+1（最大8）、毎レベル被弾後の無敵時間+0.03秒（初期1.4秒）。
- 草1本1pt、宝石10pt、通常敵25〜60pt、ボス150〜420pt。
- クリア100+ステージ番号×12pt。ボス面はさらに180pt。
- 日付ごと50pt、応援は10秒ごと5pt。広告は本物ではなく、おためし30pt（30秒間隔）。
- 旧バージョンと同じ `greenParadiseSaveV1` に保存。ポイント・強化・進行を引き継ぎます。
- 旧5ステージクリア済みの保存データでは、ステージ6が自動で開きます。
- 買って飛ばしたステージをクリア済み扱いにしないよう、クリア済み番号を別に記録します。
- 記録は同じブラウザ・同じURLに保存されます。端末間の共有やオフライン対応はありません。

### 強化の価格

次に買うレベル1〜7の価格倍率は、基本価格×[1, 2, 4, 7, 12, 20, 32]。
基本価格はジャンプ180、スピード160、エネルギー220、アイテム運240、こうげき280。
例: スピードは160 / 320 / 640 / 1120 / 1920 / 3200 / 5120pt。
すべての強化をゼロから最大にする合計は84,240pt。前半は選んだ強化を買いやすく、後半は数ステージ分ためて買う設計です。
報酬を削ったり、ためたポイントを消したりする変更はしていません。

## 開発・確認

`world.js`: ステージ生成、物理、敵、戦闘、保存データ検証。
`gimmicks.js`: エリア別仕掛けの配置、動く足場、床の性質、スイッチと危険物。
`art.js`: 地域ごとの風景、キャラクター、ボス、演出の描画。
`music.js`: エリア別のオリジナルBGM譜と画面ごとの曲選択。
`game.js`: 画面、入力、音、ポイント、ブラウザ保存。

`npm test` で基本地形の50面通過、左右両方向のジャンプ、ボス技、ダメージ、ドロップ、保存移行、16種の配置と仕掛けの物理を確認します。
仕掛けを有効にした全50面の通過も初期能力で確認します（この移動テストのみ敵を除外し、蒸気・つらら・ハート判定は有効）。高レベルでは空中の左右操作で着地位置を調整してください。
ブラウザテストは Node.js 20以上と Playwright の Chromium / WebKit が必要です。
ローカルサーバー起動後、`TEST_URL=http://127.0.0.1:4173 node tests/browser.cjs`。
仕掛けのスマホ操作・描画は `TEST_URL=http://127.0.0.1:4173 node tests/gimmicks-browser.cjs`。
Playwright が別の場所にある場合は `PLAYWRIGHT_MODULE` でモジュールの絶対パスを指定できます。
テストは独立したブラウザ保存領域を使い、実際のプレイヤーの記録は変更しません。

更新時は `world.js` の `VERSION` と `index.html` のバージョン・CSS/JSのクエリをそろえて増やします。
スタートボタンの下の中央で、新しいバージョンになったか確認できます。
iPhone実機での長押しメニューやホーム画面からの表示は、公開後にも実機確認してください。
